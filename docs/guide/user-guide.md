# 管理台使用教程

从初始化到第一条回复的路线是：初始化 → 模型能力（接口、策略、工具）→ 运行平台（账号、群聊）→ 会话管理。**群聊管理**保存长期配置；**会话管理**查看当前连接、审批、聊天记录、费用和逐条记忆，不在此处重复填写身份策略。

## 推荐配置顺序

1. 首次部署在初始化页使用 `SYS_SECRET` 完成数据库建表与默认策略/价格播种；已有部署用初始化页的“补齐默认配置”按钮显式补缺。二者均不覆盖手工修改的单价或策略；仅默认身份、默认对话可直接选，默认语音未配置合成模型、生图工具默认关闭。
2. **模型能力 → 接口管理 → AI 供应商**：填写兼容 API 地址、密钥和实际支持的模型；**AI 模型价格**核对单价来源。现有价格快照含 50 个文本模型、2 个 TTS 及 4 个图像模型，供应商账单不同须手工调整。
3. **模型能力 → 策略管理 → 身份策略**：设置默认**人设**、基础系统规则、聊天模型及授权的 Skills/MCP/Rules/工具。**对话策略**配置流式与工具轮数；它与身份策略在群聊中都必选。**语音策略**仅在确实配置 TTS 时选择；**AI 费用策略**保存复用预算（默认 `0/0/0` 为无限额）；**记忆策略**保存如何记住、容量和遗忘期限。
4. **运行平台 → 插件管理 / 平台账号**：确认群聊助手插件并填写 QQ AppID、AppSecret。
5. **运行平台 → 群聊管理**：绑定账号和群/用户 OpenID，选择身份、对话策略（必选），按需选择语音、费用、记忆策略；只填写该群自己的 owner、准入、群专属规则及工具审批等。群不能额外授权身份未允许的工具。
6. **运行平台 → 会话管理**：在群里 @ 机器人后，检查连接、工具审批、聊天记录的成本及错误；这里管理真实会话记忆条目，而不是修改记忆策略。

如果默认身份的模型尚未填、语音模型为空或生图工具仍关闭，必须先完成对应配置；保存了策略名称并不意味着供应商调用已可用。

## 配置前准备

1. 部署并初始化持久化存储，设置 `SYS_PASSWD` 与 `SYS_SECRET`。
2. 准备 QQ 机器人 AppID、AppSecret，以及 QQ 开放平台回调配置。
3. 准备兼容项目请求格式的 AI API 地址和密钥。若使用 MCP，再准备其地址、认证信息和管理员审查过的工具 allowlist。
4. 确认要测试的群聊/私聊 OpenID。会话管理列表由保存的会话策略生成，不会自动扫描或导入历史聊天。

## 第一次配置

### 1. 登录管理台

打开部署域名的管理入口，用 `SYS_PASSWD` 登录。管理 API 需要有效管理员 session；首次使用时按部署页说明完成数据库初始化。

### 2. 配置供应商、身份和对话

在“模型能力 → 接口管理 → AI 供应商”保存实际支持的模型，再核对“AI 模型价格”。缺价的**聊天文本**按默认 $3 输入 / $15 输出每百万 token 估算；图片须按图像模态价格或管理员填写的每张兜底价计费，不能默认为免费。图片预置为公开价目快照，实际账单以供应商为准。

在“策略管理 → 身份策略”编辑可复用的**默认人设**和**基础规则**，选择供应商/模型、Skills/MCP/Rules 与工具授权；在“对话策略”编辑流式回复、工具轮数及输出参数。两者缺一不可。`/role` 选中的会话人设会**替代**身份默认人设，清除选择后恢复默认，绝不叠加两份人设。

费用策略复用每日/每月/总限额，`0` 表示不限制。记忆策略可选择仅由 owner 用 `/save` 明确写入、自动提取候选等待管理台确认，或显式开启自动保存；默认每会话 100 条、每条最近更新后 7 天过期，当前自动保存仅从 owner 的消息提取。未选记忆策略则记忆关闭。语音策略的合成模型留空表示关闭 TTS。

### 3. 确认机器人插件与账号

在“运行平台 → 插件管理”确认群聊助手（`elysia-best/plugin-chatbot`）已启用；到“平台账号”绑定 QQ AppID 与 AppSecret。凭据由服务端使用 `SYS_SECRET` 加密，管理台不回显明文；更换此密钥前应准备原数据的恢复办法。

### 4. 绑定群聊并选择策略

在“运行平台 → 群聊管理”依次选择机器人账号、会话类型，填写群/用户 OpenID 与管理员 ID。**身份与对话策略两项必选且始终显示；语音、费用、记忆策略同样可见但可不选**。群专属规则只追加在身份基础规则后；模型如需覆盖，供应商与模型须一起选择；群不能增加身份未授权的工具。工具审批支持逐项、全部需要审批、全部允许；全部允许会跳过人工审批，启用前核对外部写入工具风险。

同一个群管理记录可以绑定多个 OpenID，但对话上下文与会话记忆按真实 OpenID 隔离。群 OpenID 与用户 OpenID 属不同范围，不能混填。高级设置仅放时区和预留模式参数，不隐藏核心策略。

### 5. 检查运行和实际费用

根据 `API_METHOD` 配置 QQ 接入：`websocket` 使用 Gateway，**不要**将 `/webhook/qq` 当作当前事件入口；`webhook` 才需要 QQ 回调 URL、签名头和原始 JSON body。在所选会话中 @ 机器人，然后进入“会话管理”检查连接、审批、聊天记录、成本详情及错误。`/openid` 可核对 QQ 用户与群标识；不要在公开群发送密钥或隐私数据。

## 会话管理与运行命令

“会话管理”查看在线状态、工具审批、按会话筛选的聊天记录与费用、逐条记忆及运行中的紧急静默/一次性提示/上下文重置；长期模式和审批规则在“群聊管理”配置。记录总费用由同一事件的模型/图像/语音调用合计，悬浮可查 token、计价来源和是否估算。空列表先检查账号、群聊绑定与有效 OpenID；历史聊天不会自动生成策略。

常用命令（权限以会话策略和身份为准）：

| 命令 | 用途 |
| --- | --- |
| `/help` | 查看当前身份可用的命令 |
| `/status` | 查看会话运行信息 |
| `/reset` | 重置会话上下文 |
| `/mode` | 管理运行模式 |
| `/role` | owner 管理并切换本会话人设，覆盖身份默认人设 |
| `/save <name> <内容>` | owner 明确保存当前会话记忆（须选择记忆策略） |
| `/memory` | 查询/管理本会话记忆，不是账号共享项目记忆 |
| `/openid` | 查看当前用户与群聊 OpenID |
| `/approvals`、`/approval`、`/approve`、`/reject` | 查看、批准或拒绝待审批工具调用 |
| `/wake` | 查看或取消持久化计划唤醒（平台能力适用时） |
| `/tools` | 在策略既有权限范围内额外禁用工具 |

对于 MCP 工具，远端 `readOnlyHint` 不构成信任证明，必须先通过管理员配置的 MCP 允许列表及身份授权；群可以进一步禁用工具或设置审批。默认有副作用的工具需要 owner 审批；管理员若在群里选择“全部允许”，则会跳过人工审批，请仅对可信群使用并检查审计记录。管理台“待审批操作”可先编辑 JSON 参数；保存参数本身不会执行工具，仍需 owner 批准。

## 人设与记忆

身份提供默认**人设**。`/role` 选中的会话人设替代身份默认人设，取消选择后恢复，不能把两份人设当系统规则叠加。身份系统规则与群专属追加规则另存一处，不要把授权边界只写在提示词里。账号共享项目记忆与当前会话记忆属于不同作用域；后者存在数据库独立记录并可在“会话管理”逐条管理、审核候选和到期清理。`/save`、`MemoryWrite`/`MemoryForget` 等明确写入仅 owner 可用；选自动记忆时，当前实现仅从 owner 消息直接写入，其他群成员的内容只可能以候选形式等待审核。

在开放记忆或 MCP 前，先确认参与者、数据范围和保留时长。模型输出、联网搜索结果、Skills/Rules 和外部文档都应当作为不可信内容处理。

## 日志与隐私

`LOG_RECORD` 默认关闭。启用后会记录用户/会话标识、消息内容、模型/工具状态、用量和错误；有效期最多 30 天，并需要配置定时物理清理。参见[日志保留与清理](/operations/log-retention)。不要将凭据或敏感隐私放进提示词、群聊或日志。

## 常见问题

- **会话列表为空**：检查是否已有平台账号、已保存群聊/私聊策略及有效 OpenID；仅配置账号不会发现聊天记录。
- **模型请求失败**：核对 API 地址、密钥、模型 ID、媒体能力声明及供应商额度；检查部署日志时不要泄露密钥。
- **回复未发送**：先看当前接入方式是否是 WebSocket Gateway，再核对账号、身份/对话策略、会话 OpenID、白名单与 QQ 发送权限。Webhook 模式才检查 `/webhook/qq` 签名。
- **工具等待审批**：在会话管理检查已授权工具的名称与参数，再由 owner 批准或拒绝；不能凭工具自报只读决定放行。
- **成本显示估算**：文字缺价用默认单价；生图仅返回 total_tokens 时按平均价估算，无可计费用量时使用管理员配置的单张兜底价。估算不等于供应商实际账单，检查费用策略是否不限额。
